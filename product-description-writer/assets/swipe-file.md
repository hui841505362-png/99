# 句式库（Swipe File）

不是让你抄，是让你知道"好句子长什么样"。写作时按需参考，不要照搬。

---

## 一、Hook 分档速查

| 起手式 | 示例 |
|---|---|
| 任务式 | 「切熟透的番茄，不压烂。」 |
| 痛点式 | 「再也不用跪在地上擦柜子底下。」 |
| 场景式 | 「早上 7 点，一手抱娃一手开门的时候。」 |
| 对比式 | 「比叫一次师傅上门便宜，还快。」 |
| 人群式 | 「给每周飞两趟、只带登机箱的人。」 |
| 反常识式 | 「这块砧板，越用越平整。」 |
| 数字式 | 「15 分钟充满，用一整天。」 |
| 边界式 | 「不适合追求极致轻量的人 —— 它重 1.2kg。」 |

## 二、要点句式的五种连接

| 连接 | 句式 | 示例 |
|---|---|---|
| 意味着 | 特征 + 意味着 + 利益 | 「316 不锈钢内胆，意味着柠檬水随便装，不留金属味。」 |
| 所以 | 特征 + 所以 + 利益 | 「密封圈可拆，所以洗完能晾干再装回去，不会发霉。」 |
| 破折号 | 特征 —— 利益 | 「一键弹盖 —— 开车时不用腾出第二只手。」 |
| 对比 | 比【熟悉物】更【感受】 | 「280g，比一听可乐还轻。」 |
| 场景 | 在【时刻】，你【动作】 | 「宽 5.4cm 的口径，整只手能伸进去洗。」 |

## 三、CTA 分档

| 档位 | 示例 |
|---|---|
| 专业克制 | 「确认尺寸后下单，30 天无理由退换。」 |
| 温暖亲和 | 「带一个回家，明早就能用上。」 |
| 活泼俏皮 | 「挑个颜色，明天就让它上岗。」 |
| 硬核技术 | 「查看完整测试报告，或直接下单。」 |
| 奢华克制 | 「选一只，用上十年。」 |

**共同点：都复述了利益，没有一句是裸的"立即购买"。**

## 四、改造对照（Bad → Good）

| Bad | 问题 | Good |
|---|---|---|
| 优质面料，舒适透气 | 空词 | 鞋面 480 个透气孔，35℃ 走一小时不闷脚 |
| 大容量设计 | 无参照 | 20L，装得下 15 寸笔电 + 健身服 + 午饭 |
| 安装简便 | 无细节 | 4 颗螺丝，附带扳手，一个人 15 分钟装完 |
| 品质保证，放心购买 | 空承诺 | 2 年质保，坏了寄回换新不修 |
| 适合各种场合 | 太泛 | 通勤、出差、周末露营都能背，配西裤也不违和 |
| 采用先进技术 | 术语无解释 | 双层真空，早上倒的咖啡下午三点还烫 |
| 轻便易携带 | 无数字 | 折叠后 32cm，塞进登机箱还有余地 |
| 经久耐用 | 无证据 | 铰链通过 2 万次开合测试，按每天 5 次约 10 年 |

## 五、禁用词替换表

| 禁用 | 换成 |
|---|---|
| 高品质 / 优质 | 说出具体是什么材质、什么标准 |
| 效果好 | 说出"好"到什么程度、在什么条件下 |
| 人性化设计 | 说出这个设计让人少做了哪个动作 |
| 多功能 | 逐一列出 3 个具体用途 |
| 性价比高 | 拆成单次成本，或列出随附配件价值 |
| 热销 / 爆款 | 用真实数据：已售出 XX 件 |
| 匠心 / 极致 | 删掉 |
