# 输入收集表（Intake Brief）

开写前向需求方收集。规格表太薄时，**只问一个问题** —— 挑下面最有区分度的那个。

---

## 一、必填三项

| 项目 | 说明 | 缺失时怎么办 |
|---|---|---|
| **规格 / 特性清单** | 原始参数，越全越好，主文案再从里面挑 | 见下方"补问清单" |
| **目标客户** | 谁买、什么场景、什么情绪下买 | 用一句话反推，写进交付备注 |
| **品牌声音** | 五档光谱中的哪一档 | 从竞品/现有物料反推，见 voice-calibration.md |

---

## 二、加分项（有就更好，没有也能写）

- 竞品链接或文案（用于拉开距离）
- 现有详情页（用于延续调性、避免重复）
- 真实用户评价（**最好的利益来源**，比规格表好用）
- 退货 / 差评原因（**最好的异议来源**）
- 主图与场景图（判断视觉与文案是否重复）

---

## 三、规格表太薄时的补问清单

按品类挑**一个**问：

| 品类 | 优先索取 |
|---|---|
| 服饰鞋包 | 面料克重 / 版型偏大还是偏小 / 模特身材参照 |
| 3C 数码 | 实测续航 / 不兼容清单 / 保修政策 |
| 美妆个护 | 全成分表 / 适用肤质 / 开盖后保质期 |
| 家居家纺 | 内部可用尺寸 / 安装耗时 / 板材环保等级 |
| 食品 | 配料表 / 每份营养值 / 过敏原 |
| 户外运动 | 测试标准与条件 / 承重上限 / 可维修部件 |

**问法示例**：「保温这块，有没有实测数据？比如 6 小时后水温多少度 —— 有这个数字，文案比写'保温效果好'强十倍。」

---

## 四、一句话确认单

收集完，用一段话复述给用户确认，避免返工：

```
确认一下再动笔：
产品是 [XX]，卖给 [谁 / 什么场景]，
主推 [3-5 个核心规格]，
声音走 [专业克制 / 温暖亲和 / 活泼俏皮 / 硬核技术 / 奢华克制]。
详情页里不写 [禁忌项，如价格、竞品名]。
对吗？
```

得到确认再写。**声音定位错误导致的返工，比多问一句贵得多。**
