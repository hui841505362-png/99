复制本模板填充。区块顺序固定，不要调换 —— Details 永远在最后。

```

[引言 2-3 句，单句 ≤25 字。承接 Hook，给出核心购买理由。]

- **[利益词前置 4-8 字]**，[机制 + 利益，20-40 字]
- **[利益词前置 4-8 字]**，[机制 + 利益，20-40 字]
- **[利益词前置 4-8 字]**，[机制 + 利益，20-40 字]
- **[利益词前置 4-8 字]**，[机制 + 利益，20-40 字]

**Good to know**
• [异议 1：真实硬伤必须明说]
• [异议 2]
• [异议 3，最多三条]

**[CTA：10-20 字，复述利益，不要裸的「立即购买」]**

---

[规格行 / 表格，见 details-block-template.md]
```

---

## 各区块填写要点

| 区块 | 要求 | 常见错误 |
|---|---|---|
| Hook | 能独立成立，读完就知道解决什么问题 | 以品牌名、品类名、"高品质"开头 |
| 引言 | 2-3 句，单句 ≤25 字 | 一段到底，没有断句 |
| 要点 | 3-5 条，每条只说一件事，前 4-8 字加粗 | 整句加粗；一条里塞两件事；超过 5 条 |
| Good to know | ≤3 条，说真实硬伤 | 全是"质量保证"类空话；超过 3 条 |
| CTA | 含利益词 | "立即购买""加入购物车" |
| Details | 全部数字、尺寸、材质、保养 | 缺失；或反过来把参数堆在主文案 |

---

## 交付时附在文案后面的两段

```
丢弃的规格及理由：
- [规格]：转译不出买家利益 / 竞品都能说 / 与决策无关

无法从输入支撑、未写入的宣称：
- [宣称]：来源未提供 [依据]，如需使用请补充
```

这两段不能省。它是让需求方信任你没瞎编的凭证。
