# Details / Specs 规格块模板

主文案负责打动人，Details 负责让"已经心动、需要确认"的人下单。**来源里的每个数字都要在这里出现**，一个都不能漏。

---

## 通用写法

两种形态，按详情页排版能力二选一：

**表格（推荐，适合参数多）**

```
| 属性 | 值 |
| --- | --- |
| 容量 | 500ml |
| 净重 | 280g |
```

**单行分隔（适合参数少）**

```
容量 500ml ｜ 内胆 316 不锈钢 ｜ 净重 280g ｜ 口径 5.4cm ｜ 高 22cm
```

规则：一行不超过 5 项；单位写在数字后不加空格；同一类属性放同一行。

---

## 分品类必填字段

### 服饰鞋包
品类 / 版型 / 面料成分及克重 / 里料 / 尺码范围 / 模特身材与穿着尺码 / 洗涤方式 / 产地

### 3C 数码
型号 / 接口类型 / 电池容量 / 续航（标注测试条件）/ 充电时长 / 净重 / 外形尺寸 / 兼容清单 / 保修

### 美妆个护
全成分 / 净含量 / 适用肤质 / 质地 / 香型 / 开盖后保质期（PAO）/ 过敏原 / 生产许可

### 家居家纺
外形尺寸 / **内部可用尺寸** / 材质与环保等级 / 净重 / 承重 / 安装方式与耗时 / 是否需工具 / 保养

### 食品
配料表 / 净含量与份数 / 每份营养值 / 保质期 / 储存条件 / 过敏原 / 食用方式

### 户外运动
材质与旦数 / 防水等级（**含测试条件**）/ 耐磨测试 / 净重 / 收纳尺寸 / 承重上限 / 可维修部件 / 保修范围

---

## 容易漏写的五项

1. **测试条件** —— "防水"必须写 IP 等级 + 深度 + 时长；"续航"必须写使用场景。
2. **不兼容清单** —— 写清楚"不支持什么"，比只写"支持什么"更能降退货。
3. **保养方式** —— 能不能机洗、能不能晒，是家居和服饰的高频问题。
4. **过敏原 / 安全警示** —— 合规要求，也是信任来源。
5. **包装内容** —— 含哪些配件、赠品、说明书、保修卡。

---

## 禁止出现在 Details 里的内容

- 营销形容词（优质、高端、匠心）—— Details 是事实区
- 主文案里已经说过的利益句
- 无法验证的承诺（"终身""永久"）
