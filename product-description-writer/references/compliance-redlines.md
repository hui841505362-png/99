# 合规红线（Compliance Redlines）

原则：**没有来源支撑的宣称，一律不写。** 拿不准的，写成可验证的事实，或改写为不承诺的表达。

---

## 一、中国《广告法》绝对化用语（不要用）

**明令禁止类：** 国家级、最高级、最佳、第一、顶级、极品、绝无仅有、史无前例、独一无二、首个首选、全网最低、销量第一、遥遥领先。

**灰色高危类：** 唯一、冠军、王牌、领导者、开创者、革命性、颠覆、神器、必备。

**例外：** 有客观证据且标明出处和时间的排名类表述（如"2025 年 Q1 天猫 XX 类目销量第一，数据来源：生意参谋"）在特定条件下可用，但需要用户确认有完整证据链 —— **默认不用**。

### 安全替换表

| 禁用 | 替换为 |
|---|---|
| 最好的材质 | 我们选了 XX 材质，因为…… |
| 全网最低价 | 同一规格，我们对比了 5 家 |
| 销量第一 | 已售出 XX 万件（真实数据） |
| 顶级工艺 | 由 XX 工厂生产，该厂为 XX 品牌代工 |
| 独一无二 | 市面上少见的做法是…… |

## 二、功效与医疗宣称（高危）

**绝对不要写**：治疗、治愈、根治、消炎、杀菌（需资质）、防癌、降血压血糖、减肥、瘦身、祛疤、生发、壮阳、提高免疫力、排毒。

**化妆品/护肤品**（中国《化妆品监督管理条例》）：非特殊化妆品不得宣称美白、防晒、祛斑、染发、防脱等特殊功效。

**安全写法**：把功效改成**使用感受和物理事实**。

| 危险 | 安全 |
|---|---|
| 淡化细纹 | 质地滋润，上妆不易卡粉 |
| 杀菌除螨 | 60℃ 水温可洗，配合除螨仪使用 |
| 缓解颈椎疼痛 | 支撑高度 8cm，颈部有承托点 |
| 提高免疫力 | 每份含维生素 C 100mg（占 NRV 100%） |

## 三、美国 FTC / 欧盟要点

- **Substantiation（证据先行）**：任何性能宣称在发布前就应有可靠证据，事后补救无效。
- **Made in USA**：需"全部或几乎全部"在美国制造，否则必须说明。
- **Testimonials**：用户评价必须真实，不得代写；需披露是否付费或赠送产品。
- **欧盟健康宣称**：只有经 EFSA 批准的健康声称清单内的说法可用。
- **CE / FCC / UL**：仅在确已取得认证时标注，且型号需对应。

## 四、平台规则（亚马逊 / 独立站）

| 平台 | 红线 |
|---|---|
| 亚马逊 | 禁"#1 Best Seller"自制标签、禁引导留评、禁站外链接、禁"环保/有机"无认证宣称、禁提及竞品名做比较 |
| 独立站（Shopify 等） | 支付与退款政策需真实一致；健康类受广告投放平台二次审核 |
| 谷歌购物 | 禁虚假促销价、禁虚假稀缺倒计时 |

**虚假稀缺**（原 SKILL.md 明令禁止）：倒计时、库存告急、仅剩 N 件 —— 必须是真实数据驱动，否则不写。

## 五、需要证据才能写的内容清单

写之前，确认来源里有对应依据：

- [ ] 具体数字（容量、续航、承重、次数、百分比）
- [ ] 测试标准与条件（"防水"必须写 IP 等级和深度时长）
- [ ] 认证名称与证书编号区间
- [ ] 材质成分比例
- [ ] 产地
- [ ] 售出数量、用户数、复购率
- [ ] 对比类表述（"比 XX 轻 30%"需有对照物）
- [ ] 时间承诺（"24 小时发货""终身保修"）

**任一项来源里找不到 → 不写，或标注 `[待核实]` 交给用户补。** 这比猜一个数字安全得多。

---

## 六、遇到"帮我写得再夸张点"

不要直接拒绝，给**合规的替代方案**：

| 用户想要 | 合规做法 |
|---|---|
| 「写最好的」 | 写具体：用了什么、为什么这个选择更好 |
| 「加个销量第一」 | 用真实数据，或改成"上架 3 个月补货 4 次" |
| 「说能治好」 | 改成使用场景 + 真实用户反馈（需授权） |
| 「写全网最低」 | 改成"包含 XX 配件，单独购买需 XX 元" |
| 「制造紧迫感」 | 用真实的季节性/限量批次/生产周期 |
