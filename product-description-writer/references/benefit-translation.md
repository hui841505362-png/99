# 卖点转译手册（Feature → Benefit）

把规格参数翻译成买家在乎的东西。参数是信任的锚，利益是欲望的钩，两者都要留。

---

## 一、核心公式

```
特征（可验证的事实） + 机制（为什么） + 利益（买家得到什么）
```

套用句式：

| 类型 | 句式 |
|---|---|
| 直译式 | 「316 不锈钢，意味着海边浴室的盐雾也锈不透它。」 |
| 场景式 | 「折叠后只有 32cm，塞进登机箱还有余地。」 |
| 对比式 | 「比上一代轻 180g —— 单手举着拍完一支 vlog 也不抖。」 |
| 痛点式 | 「鞋头加宽 4mm，脚趾终于不用叠着走路。」 |
| 消除式 | 「免工具拆装，搬家时不用再翻出那把六角扳手。」 |
| 数字式 | 「充电 15 分钟，用一整天。」 |

**关键：利益必须落到"买家的身体、时间、钱、情绪、社交形象"五者之一。** 落不到这五项的，都不是利益。

---

## 二、利益真伪三问

写完一句转译，逐条过：

1. **谁在乎？** 能说出具体哪类买家在乎这件事。说不出 → 删。
2. **会改变行为吗？** 知道这点之后，买家的决策会变吗？不变 → 删。
3. **竞品能原样说吗？** 如果所有同行都能一模一样地说 → 它不是卖点，是入场券，别占主位。

三问全过 = 可以放主文案。过两问 = 放 Details 块。只过一问 = 丢掉。

---

## 三、分级示例

同一个参数，三种写法：

| 层级 | 示例（保温杯 316 不锈钢内胆） |
|---|---|
| 差 | 「采用优质 316 不锈钢材质，品质卓越。」（"优质""卓越"是空词，无信息） |
| 中 | 「316 不锈钢内胆，耐腐蚀。」（有事实，但没说对买家意味着什么） |
| 好 | 「316 不锈钢内胆意味着咖啡、柠檬水、运动饮料随便装 —— 不会留下金属味，也不会被果酸蚀出斑点。」 |

判据：**读完之后，买家脑子里能浮现一个具体的使用画面。** 浮现不出来就是没转译到位。

## 四、按参数类型找转译入口

| 参数类型 | 转译方向 | 示例 |
|---|---|---|
| **材质** | 耐用 / 触感 / 安全 / 气味 | 「长绒棉，洗 30 次还是软的，不起球」 |
| **尺寸容量** | 装得下什么 / 放得进哪里 | 「11 寸，正好装下 13 寸笔电 + 充电器 + 水壶」 |
| **重量** | 携带负担 / 单手操作 | 「1.2kg，单手拎着走 20 分钟不勒手」 |
| **工艺结构** | 寿命 / 稳定性 / 免维护 | 「一体成型，没有焊缝，也就没有开裂的地方」 |
| **技术参数** | 实际体验阈值 | 「6500mAh，重度使用一天还剩 20%」 |
| **认证** | 安全背书 + 具体含义 | 「通过 OEKO-TEX 100 认证，婴幼儿可直接接触皮肤」 |
| **配件赠品** | 省下的钱 / 省下的事 | 「随附替换滤芯 3 只，够用一年，不用再单独下单」 |
| **包装** | 送礼体面 / 开箱体验 | 「礼盒装，拆开就能送，不用再找包装纸」 |

## 五、常见错误清单

| 错误 | 表现 | 修正 |
|---|---|---|
| **同义反复** | 「精心设计，做工精良」 | 删掉，或换成可验证的细节 |
| **术语堆砌** | 「IP68 级防尘防水」 | 加一句「泡在 1.5 米水里 30 分钟照样用」 |
| **空词占位** | 高端 / 优质 / 卓越 /匠心 / 极致 | 全部替换为具体事实或删除 |
| **假利益** | 「让你更自信」 | 太抽象，退回到「领口加衬，洗后不塌」 |
| **参数搬家** | 直接把规格表重抄一遍 | 主文案只放 3-5 个转译后的利益，其余下沉到 Details |
| **过度承诺** | 「永不褪色」「彻底解决」 | 改成有限定条件的表达，见 `compliance-redlines.md` |

---

## 六、丢弃原则

转译不出利益的参数，**不要硬凑**。处理方式：

1. 放到 Details 块 —— 它仍然服务"参数党"的决策，只是不占主文案位置。
2. 直接丢 —— 并在交付时向用户说明丢弃理由（这是原 SKILL.md 明确要求的动作）。
3. 反向利用 —— 有些"缺失"反而是卖点：「没有 APP、没有蓝牙、没有固件升级 —— 插上就用，永远不用等更新。」
