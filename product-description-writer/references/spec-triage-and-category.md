# 规格筛选与品类打法（Spec Triage & Category Playbooks）

一份规格表可能有 30 项，主文案只放得下 3-5 个转译后的利益。筛选决定成败。

---

## 一、三分法：留存 / 下沉 / 丢弃

| 归类 | 判据 | 去向 |
|---|---|---|
| **留存（3-5 项）** | 能转译成买家在乎的利益，且竞品难以照搬 | 主文案要点 |
| **下沉（其余全部）** | 决策需要，但不打动人：尺寸、重量、材质成分、保修 | Details 块 |
| **丢弃** | 转译不出利益，也不是决策依据 | 不写，并向用户说明丢弃理由 |

**快速排序法**：把每项规格问一遍"如果竞品也有这个，我还能怎么写？" —— 答不上来的，说明它不是差异化点，下沉。

---

## 二、规格表的三种典型缺陷

| 缺陷 | 表现 | 处理 |
|---|---|---|
| **太薄** | 只有品名和材质 | 向用户提**一个问题**，要那个"竞品都不写"的细节。不要自己脑补填充。 |
| **太厚** | 30+ 项技术参数 | 全部下沉，主文案只挑 3-5 项转译 |
| **全是营销话术** | "优质""匠心""高端" | 要求用户提供可验证的事实，否则无法落笔 |

**"问一个问题"的原则**：问最有区分度的那个。例如卖保温杯就问保温实测数据，卖椅子就问坐高和承重，卖服装就问版型和面料克重。

---

## 三、六大品类打法

### 服饰鞋包
- 买家真正在意：**版型合不合身 / 面料手感 / 会不会起球变形**
- 必留规格：版型描述、面料成分与克重、尺码建议、洗护方式
- 常见坑：只写"均码""标准尺码"；不写模特身材参照；回避"偏小/偏大"

### 3C 数码
- 买家真正在意：**兼容性 / 续航 / 上手难度**
- 必留规格：接口与适配清单、电池容量与实际续航、重量、保修
- 常见坑：参数堆砌；只写容量不写实际使用时长；不写不兼容的情况

### 美妆个护
- 买家真正在意：**适不适合我的肤质 / 会不会过敏 / 使用感受**
- 必留规格：成分表、适用肤质、质地、香型、容量与用量（可用多久）
- 常见坑：越界做功效宣称（见 `compliance-redlines.md`）；不写过敏原

### 家居家纺
- 买家真正在意：**尺寸放不放得下 / 好不好打理 / 有没有味道**
- 必留规格：外形尺寸、安装方式与耗时、材质、洗护方式
- 常见坑：只给外形尺寸不给内部可用尺寸；回避气味问题；不写安装难度

### 食品
- 买家真正在意：**口味 / 成分干净与否 / 保质期与储存**
- 必留规格：配料表、净含量与份数、保质期、储存条件、过敏原
- 常见坑：做保健功效暗示；不写过敏原；不写开盖后保存期限

### 户外运动
- 买家真正在意：**极端环境能不能扛住 / 重不重 / 坏了怎么修**
- 必留规格：防水/耐磨等级及其测试条件、重量、收纳尺寸、可否维修
- 常见坑：只写 IP68 不写测试深度时长；不写承重上限；不写保修范围

## 四、"竞品不写的细节"清单

当规格表太薄时，按品类优先索取这些：

| 品类 | 优先索取 |
|---|---|
| 服饰 | 面料克重、版型偏大/偏小、模特身材参照 |
| 3C | 实测续航、不兼容清单、固件升级政策 |
| 美妆 | 全成分表、开盖后保质期（PAO） |
| 家居 | 内部可用尺寸、安装耗时、板材环保等级 |
| 食品 | 配料表前三位、每份营养值、过敏原 |
| 户外 | 测试标准与条件、可维修部件清单 |

---

## 五、交付时必须说明的两件事

原 SKILL.md 明确要求，交付时附在文案后面：

1. **丢弃了哪些规格，为什么** —— 例："未使用'礼盒装'做主文案，因为它不产生利益差异；已放入 Details。"
2. **哪些宣称无法从输入中支撑** —— 例："文案中未写'保温 12 小时'，来源仅提供保冷 12 小时；如需使用请提供保温实测数据。"
