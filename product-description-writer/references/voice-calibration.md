# 品牌声音校准（Voice Calibration）

同一件产品，用错语气比写错卖点更致命 —— 买家会直觉地觉得"这不是我的牌子"。

---

## 一、快速定位：五档声音光谱

| 档位 | 适用品类 | 句长 | 词汇 | 人称 | 标点 |
|---|---|---|---|---|---|
| **专业克制** | 护肤、医疗器械、B2B、金融 | 中长，结构完整 | 精准、有术语但不炫 | 我们 / 您 | 少用感叹号 |
| **温暖亲和** | 母婴、家居、食品、礼品 | 中短，有停顿 | 生活化、具象 | 你 / 咱们 | 可用逗号制造语气 |
| **活泼俏皮** | 零食、潮玩、宠物、年轻服饰 | 短句为主 | 口语、拟声、网络语需克制 | 你 | 感叹号可用，别连续 |
| **硬核技术** | 3C、摄影、户外装备、工具类 | 中长，允许从句 | 参数、标准、测试条件 | 我们 | 几乎不用感叹号 |
| **奢华克制** | 珠宝、高端家具、酒、香氛 | 长句，节奏舒缓 | 抽象 but 克制，留白多 | 无主语 / 您 | 极少标点修饰 |

**判断捷径：看这个品牌的买家是在"解决问题"还是"表达身份"。** 前者偏上前两档，后者偏上后两档。

## 二、同一卖点，五档写法对照

卖点：包身采用 1680D 弹道尼龙。

| 档位 | 写法 |
|---|---|
| 专业克制 | 「1680D 弹道尼龙包身，抗撕裂与耐磨损均通过实测验证，适合高频通勤使用。」 |
| 温暖亲和 | 「包身用了做军包的那种尼龙料子，天天挤地铁蹭来蹭去，也不容易起毛。」 |
| 活泼俏皮 | 「这料子原本是做防弹背心的。你不用挡子弹，但挡得住早高峰。」 |
| 硬核技术 | 「1680D 弹道尼龙，经纬密度 1680 denier，马丁代尔耐磨 50000 转以上。」 |
| 奢华克制 | 「弹道尼龙，最初为更极端的用途而生。历经十年，痕迹亦是质感。」 |

## 三、校准三问（只问一个）

声音未知时，**只允许问一个问题**。按这个顺序挑：

1. **有现成物料吗？** → 有，就直接分析，别问。
2. **竞品是谁？** → 从竞品的语气反推。想跟竞品拉开距离，就选光谱上离它最远的一档。
3. **买家在什么情绪下购买？** → 焦虑/谨慎 → 专业克制；放松/取悦自己 → 活泼或温暖；身份表达 → 奢华克制。

**真正要问的那一个问题**（当前三条都拿不到信息时）：
> "这个品牌给你的感觉，更接近【医生 / 老朋友 / 玩伴 / 工程师 / 侍者】里的哪一个？"

五个选项直接对应五档光谱，一个字都不用多解释。

## 四、从现有物料反推

拿到一段已有文案或官网 About 页时，提取这 5 个信号：

| 信号 | 观察点 |
|---|---|
| 平均句长 | 数 5 句，取中位数。中文 <15 字 = 活泼；15-30 = 亲和/专业；>30 = 奢华 |
| 人称 | 用"您"→正式；用"你"→亲近；无主语→克制 |
| 术语密度 | 每 100 字术语数 >3 = 硬核 |
| 形容词比例 | >15% = 偏感性；<5% = 偏理性 |
| 感叹号/emoji | 有 = 活泼或亲和；无 = 专业或奢华 |

**原则：模仿它，但比它干净 20%。** 品牌方往往喜欢"自己的调性，但写得更利落"。

---

## 五、常见翻车点

| 翻车 | 原因 | 修正 |
|---|---|---|
| 高端品牌写得太热闹 | 用了感叹号和网络语 | 删掉所有感叹号，句子拉长 |
| 平价品牌写得太端着 | 用"尊享""臻品" | 换成大白话，拉近 |
| 同一页语气跳来跳去 | 边写边换档 | 定档后一次性写完，再统一校对 |
| 用了竞品的调性 | 抄了竞品文案 | 选光谱上离竞品最远的一档 |
| 中英混排违和 | 中文文案里硬塞英文词 | 术语保留英文，其余全部中文化 |
